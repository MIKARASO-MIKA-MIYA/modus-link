# «Мои обращения»: единое оформление

Раздел `/tickets` подключён к существующему `HomeShell` вместе с главной. Sidebar и Header не дублируются; текущий маршрут передаётся в оболочку для подсветки меню. Другие маршруты сохраняют прежнюю оболочку до согласования следующих этапов.

Стили `src/app/tickets.css` ограничены `.workspace-registry` и используют палитру `--home-*`. Sidebar сохраняет #0A1427. Красные основные действия, белые карточки, одинаковые скругления, компактные шесть показателей, панель фильтров и таблица с пагинацией поддерживают обе темы. CSS главной и компоненты Dashboard не изменены.

Все существующие API, права, URL-фильтры, поиск, сортировка, выделение, CSV, переходы и размеры страниц сохранены. Очередь без ответственного доступна руководителю и администратору через фильтр. Кнопка сброса учитывает дополнительные фильтры; повтор загрузки обновляет все ресурсы реестра.

Для длинных списков используется обычная прокрутка страницы, для широкой таблицы — горизонтальная прокрутка. Нет ограничения высоты реестра или скрытия содержимого страницы. Сетка показателей переключается с шести колонок на три, затем на две; поля фильтров переносятся в две и одну колонку.

Проверки: typecheck, lint, 252 теста и production build прошли. DOM-тесты покрывают обе темы, три роли, реальные обработчики URL-фильтров/поиска/сортировки/пагинации, CSV/выделение, ошибки, загрузку и пустой список. Fixtures в тестах синтетические; в приложении используются существующие API. Проверки оболочки подтверждают её подключение к `/tickets`, подсветку меню и сохранение старой оболочки на `/tickets/new`.

HTTP-проверки работающего локального сервера: `/` и `/tickets` — 200; `/api/v1/health` — 200, `database: connected`. Это не подтверждает визуальную геометрию или вход в браузере. Браузерный сервис сообщил `The browser access host is unavailable`, поэтому скриншот и визуальная проверка обеих тем/размеров не выполнены.

Сборка выдала предупреждение о внешнем `D:\Projects\package-lock.json`, не входящем в текущий Git-репозиторий; сборка завершилась успешно. Backend, авторизация, модели и миграции БД не изменялись. Push и deployment не выполнялись.
