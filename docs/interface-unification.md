Административные страницы перечислены выше. Вход и регистрация — состояния существующего LoginScreen, показанного AppFrame при отсутствии сессии.

## Общие изменения

- Удалена альтернативная встроенная оболочка из AppFrame: все авторизованные страницы, включая неизвестные адреса, используют единственную HomeShell.
- Для оставшихся страниц добавлен локальный класс workspace-content; ранее утверждённые страницы сохраняют свои классы и компоновку. Длинные страницы продолжают прокручиваться.
- Сохранены существующие поиск, Ctrl+K, ролевое меню, уведомления, профиль, выход и переключатель тем. Обработчики входа, сессии и выхода не изменены.
- Sidebar использует #0A1427. Общие токены переведены на красные акценты и плоские поверхности обеих тем. Удалены градиенты и фиолетовые значения. Семантические цвета статусов сохранены.
- У входа и регистрации удалены декоративное здание и фоновые фигуры. Используются те же токены и существующий настоящий бело-красный логотип PNG; векторная фиолетовая имитация Brand удалена.
- Добавлено оформление существующих состояний 404 и ошибки страницы через not-found.tsx и error.tsx. Новые URL не добавлены. Текст внутренних ошибок не раскрывается. Это не обработчик ошибок корневого layout.
- В уведомлениях ошибка запроса больше не сопровождается утверждением об отсутствии событий.

## Удалённое и сохранённое

Удалены старая встроенная Workspace-разметка Sidebar/Header, её лишние запросы очереди и просроченных обращений, декоративная разметка входа, старый SVG Brand, 140 блоков неиспользуемых CSS-правил и связанные неиспользуемые токены. Селекторы общей разметки удалялись с сохранением используемых частей смешанных правил. Убраны названия avatar-purple, tone-purple, chart-purple и chart-lavender.

Используемые общие компоненты Modal, ErrorNotice, Loading, Brand, MetricCard и AdminDirectory сохранены. Отдельная вторая HomeShell не создана. Файлы компонентов не удалялись.

## Результаты проверок

- `npm run typecheck`: успешно.
- `npm run lint`: успешно.
- `npm test`: **605 тестов, 27 файлов — успешно**.
- `npm run build`: успешно; Prisma Client сгенерирован. Предупреждение Next.js о внешнем `D:\Projects\package-lock.json` не блокирует сборку; конфигурация не менялась.
- Инвентаризация тестом фиксирует все 13 страниц; проверяется отсутствие старых классов оболочки, декоративной разметки и CSS-градиентов.
- Компонентные тесты jsdom проверяют одну HomeShell, активные ссылки, ролевое меню EMPLOYEE/MANAGER/ADMIN, переходы, выход, уведомления и ошибки для обеих тем. Выполнены также все существующие регрессионные тесты реестра, создания/карточки обращения, аналитики и справочников. Проверки контраста общих цветов проходят.
- HTTP на `http://127.0.0.1:3001`: все 13 маршрутов возвращают 200, неизвестный адрес — 404, `/api/v1/health` — 200. Для динамической страницы использован тестовый UUID; ответ HTML 200 не подтверждает наличие обращения или доступ к нему.

## Ограничения проверки

Браузерный сервис возвращает `The browser access host is unavailable`. Скриншоты, реальная отрисовка в обеих темах, размеры desktop/mobile, клавиатурное поведение в браузере и переходы под реальными сессиями всех ролей **не подтверждены**. Jsdom не измеряет геометрию, контраст наложений или визуальные дефекты.

В рамках этого этапа не выполнялись реальные операции создания/редактирования с PostgreSQL, вход/регистрация через браузер и отдельный DB integration suite. Серверные права и бизнес-логика не изменялись; их автоматические регрессионные проверки входят в общий test. Имеющиеся ограничения серверных справочников и бизнес-логики этим визуальным этапом не устранялись.

Git push и деплой не выполнялись.
